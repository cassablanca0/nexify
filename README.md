# nexify
⚡ Nexify

Nexify is a lightweight, client-side optimization mod designed specifically for Crystal PvP.

It improves packet handling and reduces unnecessary network spam to provide a cleaner, more stable combat experience — without modifying vanilla mechanics.

🚀 Features

⚡ Improves packet stability during Crystal PvP

🎯 Smoother rotation handling

🧱 More consistent crystal placement

💥 Cleaner attack responsiveness

🪶 Lightweight and client-side only
